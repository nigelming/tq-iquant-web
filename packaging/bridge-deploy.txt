桥脚本部署说明（创懿基金量化投资平台）
================================================

本目录下的桥脚本是**明文 Python 文件**，不编译进主程序，必须由对应交易终端
用自己的 Python 解释器加载运行。QMT、掘金、同花顺、通达信四个通道同级，
均为生产通道。

1) iquant_bridge.py（QMT 通道，端口 8790，股票账户）
   - 打开 QMT（iQuant）客户端 → 模型研究 / 策略编辑器 → 新建策略
   - 将 iquant_bridge.py 的全部内容粘贴进策略文件并保存
   - 在 QMT 内运行该策略；控制台出现 LISTEN 127.0.0.1:8790 即成功
   - 必须使用 QMT 自带 Python 3.6.8 运行，不要复制到平台目录执行
   - 平台侧 QMT 的 simulation 与 live 两个模式位都指向 8790（同一股票账户），
     不使用信用账户腿
   - 端口被占用时脚本会尝试礼貌踢人（GET /shutdown），仍失败请在 QMT 里
     停止旧策略或重启客户端

2) goldminer_bridge.py（掘金量化通道，端口 7801）
   - 将脚本内容粘贴/导入到掘金终端的策略里，在**掘金终端内**点击运行
   - 严禁用 uv / 项目虚拟环境启动掘金桥：gm SDK 必须在掘金终端所在解释器内
   - 平台侧只需保证桥在运行，Core 通过 http://127.0.0.1:7801 访问

平台侧配置：
   - 安装后首次启动会在数据根目录生成 config.yaml
   - iquant_bridge.simulation / iquant_bridge.live 均填 http://127.0.0.1:8790
   - 掘金 goldminer.base_url 填 http://127.0.0.1:7801
   - 通达信 TQ 路径（tdx_path）、同花顺下单程序路径（ths_ui.client_exe_path）
     也可在「系统设置」界面里直接修改，无需手改文件

注意：
   - 桥脚本内容以安装包内为准；升级平台后如需更新桥，请重新复制本目录文件
   - 两个脚本均为纯标准库实现，兼容 Python 3.6，勿引入第三方依赖
