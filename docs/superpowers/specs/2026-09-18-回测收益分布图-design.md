# 回测详情页收益分布可视化（月度热力图 / 年度分布）设计文档

## 背景

用户从独立工程 `E:\宏观模型回测引擎`（Streamlit + Plotly）中的「月度收益热力图、年度收益分布」功能得到启发，希望把同款 4 张收益分布图引入当前项目（`tq-iquant-web`）的**回测管理详情页**，直观观察组合收益的时间分布特征。

## 需求

在回测详情页（`web/src/views/Backtest.vue`）新增「收益分布」区块，包含 4 张图，**仅组合整体粒度**（不按子策略拆分）：

1. **月度收益热力图**：行=年份，列=1-12月；单元格颜色表示当月收益（正绿负红），单元内显示百分比文字；Hover 显示「YYYY年M月：收益率%」
2. **年度日收益箱线图**：每年一个箱线，展示该年日收益率的分布（中位数线加粗、异常值标注）
3. **各年月收益箱线图**：每年一个箱线，展示该年月收益率分布
4. **各年年收益柱状图**：每年一根柱，正收益绿 / 负收益红，柱顶显示年收益%

## 方案选型

**方案 A（采纳）：详情接口实时计算 + 前端 ECharts 渲染**

- 后端：`get_record_detail` 在返回前，用已加载的组合级每日快照（与 `Evaluator._daily_returns` 同口径）现场计算月度矩阵 / 年度分组统计，附加到 response。（不做落库，无需 Alembic 迁移。）
- 前端：用项目现有 ECharts（`echarts` 已引入，唯一图表库）渲染 heatmap / boxplot / bar。

否决项：
- 方案 B（回测时计算落库新表）：需新增模型 + 迁移，对单用户本地工具过度设计。
- 方案 C（纯前端计算）：把统计逻辑重复到前端、与后端口径脱节，且快照数组大时 payload 重。不采纳。

## 数据流

```
backtest_daily_snapshots (target_type='portfolio', snap_date, total_value)
  └─ get_record_detail 已加载 snaps（按 snap_date 升序）
       ├─ 取「每日最后一根 bar 的净值」→ 日净值序列（与 _daily_returns 逻辑一致）
       │    ├─ 月末净值 resample 末值 → 月净值 → pct_change → 月收益序列
       │    │    └─ (year, month, return%) → 12 列 × N 年矩阵 → 热力图
       │    └─ 日收益 pct_change 序列
       │         ├─ groupby(year) → 各年日收益数组 → 年度日收益箱线图
       │         ├─ groupby(year) 再按 month 聚合月收益 → 各年月收益箱线图
       │         └─ groupby(year) 复利累计 (∏(1+r)-1)×100% → 年收益柱状图
```

## 后端设计

**位置**：`main/core/services/backtest_service.py`，新增模块级辅助函数 `build_return_buckets(snaps)`。

**输入**：`snaps`（`BacktestDailySnapshot` ORM 列表，组合级，按日期升序）。

**输出**（dict，附加进 `get_record_detail` 返回的 `returns_buckets` 字段）：

```python
{
  "monthly_matrix": {
    "years": [2021, ..., 2026],
    "months": ["1月", ..., "12月"],
    "matrix": [[3.21, -1.05, ..., None], ...],   # row=年, col=月, 单位 %, 缺失月为 None
    "text": [["+3.21%", "-1.05%", ..., ""], ...], # 热力图单元格文字
  },
  "yearly": [
    {
      "year": 2021,
      "daily_returns": [0.012, -0.008, ...],     # 单位小数，供箱线图
      "monthly_returns": [0.031, -0.02, ...],     # 单位小数，供箱线图
      "annual_return": 0.2345,                    # 单位小数（复利）
    },
    ...
  ],
}
```

**关键实现细节**：
- 日净值序列：遍历 snaps，同一 `snap_date` 取最后一条的 `total_value`（30m/1m 等日内周期回测一天多根 bar，取日收盘；日线回测行为不变）——与 `Evaluator._daily_returns` 完全一致。
- 月收益：按 `(year, month)` 分组，取组内最后一个日净值，`pct_change`（首月无收益）。与源 `resample('ME').last().pct_change()` 等价。
- 日收益：`pct_change()` 首日 dropna。
- 年收益：当年 `∏(1 + daily_r) - 1`。
- 空/数据不足（<2 个不同商品日）：`monthly_matrix` 返回空数组、`yearly` 返回 `[]`，前端隐藏该区块。
- 返回的小数以 `float` 表示（百分比展示由前端负责，热力图 matrix 直接用 % 数值便于 visualMap）。

**API 变更**：`GET /api/backtest/records/{id}` response 增加顶层字段 `returns_buckets`（无快照/详情外的额外查询——复用已加载的 `snaps`）。

## 前端设计

**位置**：`web/src/views/Backtest.vue`
- 模板：在「回撤曲线」div 之后、「风控与拦截统计」之前插入「收益分布」区块（`section-title` + 4 个 `chart-box`，各自带 `ref` 容器）。
- 脚本：新增 4 个 ECharts 实例（如 `monthlyHeatChart`/`dailyBoxChart`/`monthlyBoxChart`/`annualBarChart`），沿用现有 `init()` / `dispose()` / `resize()` 生命周期模式（`onMounted` init、`onBeforeUnmount` dispose、`window.resize`）。
- 数据来源：`detail.value?.returns_buckets`。

**4 张图的 ECharts 实现**：

1. **月度热力图**（`series.type='heatmap'`）
   - `xAxis`：`['1月'..'12月']`；`yAxis`：年份（`inverse: true` 年份自上而下递增）
   - `visualMap`：`min/max` 取 matrix 全局最大绝对值对称，`color` 红→白→绿或使用 `['#ef4444','#f5f5f5','#10b981']`，配 `label.show = true` 用 `text` 矩阵
   - data：`matrix` 展开为 `[row, col, value]` 三元组，None 跳过

2. **年度日收益箱线**（`series.type='boxplot'`）
   - `dataset` 或后端 `yearly[].daily_returns` 转为 ECharts boxplot 的 5 数摘要（min/Q1/median/Q3/max），由前端 `boxplotData(arr)` 辅助函数计算（排序后取分位）

3. **各年月收益箱线**（同上，输入 `monthly_returns`）

4. **年收益柱状图**（`series.type='bar'`）
   - `data`：`annual_return`（转 %），`itemStyle.color`：正绿 `#10b981` / 负红 `#ef4444`，`label.show` 柱顶显示 `+x.xx%`

**类型定义**：`web/src/api/index.ts` 新增 `BacktestReturnsBucket` 接口，并在 `BacktestDetailItem` 增加 `returns_buckets`。

## 测试

**后端**（`main/core/tests/unit/test_backtest_service.py` 或新建 `test_return_buckets.py`）：
- 构造构造组合级快照 mock（构造简单的 `BacktestDailySnapshot` 列表），验证：
  - 月收益矩阵的行/列/值正确（含缺失月的 None）
  - 日/月收益分组、年复利收益计算正确
  - 跨年边界（12月底→1月初）不被错误归组
  - 日内多 bar（同日多快照）取最后一条净值
- 空快照 / 单日快照 → 返回空结构

**前端**（`web/src/__tests__/Backtest.test.ts` 扩展）：
- `boxplotData` 辅助函数：已知数组 → 正确 5 数摘要
- 详情数据含 `returns_buckets` 时，区块渲染（4 个图容器存在）；无数据时区块隐藏

## 边界条件

- 回测区间不足 2 个自然月：月度热力图只有首月之后的列有值，其余 None（正常显示零收益占位）；若完全无月收益 → 隐藏热力图并显示空态文案
- 数据不足（<2 个交易日）：`returns_buckets` 为空对象，前端隐藏整个「收益分布」区块
- 子策略收益不做（本次范围仅组合整体）

## 不做的事（YAGNI）

- 不落库、不加 Alembic 迁移、不加新表
- 不引入 Plotly（沿用 ECharts）
- 不做子策略粒度收益分布
- 不做月度收益的移动窗口/滚动统计
