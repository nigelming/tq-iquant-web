## 唯一发现的 Bug

[html_report.py](file:///d:/project/tq-iquant-web/main/core/services/html_report.py) 箱线图与前端口径不一致：

1. `_boxplot_data`（L1059-1075）仅在 values 为空时返回 None；前端 `boxplotData`（Backtest.vue L2268-2269）在样本 `<5` 时返回 null（"样本 <5 无法构成箱体，整年剔除"）。`_boxplot_data` 的 docstring 自称"与前端 boxplotData 同口径"，实际不符——1~4 样本的年份会在报告中渲染退化箱体，前端则剔除。
2. `_box_chart`（L1104-1124）先对全量年份生成 `categories`，再过滤 `box_data` 中的空值——一旦某年无箱体，箱体序列与年份轴错位（与此前前端修复过的错位 bug 同一类，违反"先完成全量统计再统一过滤"的既有教训）。

## 修复方案

### 1. main/core/services/html_report.py（仅两处定点修改）

- `_boxplot_data`：`if not values: return None` 改为 `if not values or len(values) < 5: return None`，docstring 补充"样本 <5 无法构成箱体"。
- `_box_chart`：改为先配对再统一过滤的模式——

```python
pairs = [
    (str(y.get("year")), _boxplot_data([round(r * 100, 4) for r in (y.get(key) or [])]))
    for y in yearly
]
pairs = [(c, b) for c, b in pairs if b]
if not pairs:
    return None
categories = [c for c, _ in pairs]
box_data = [b for _, b in pairs]
```

其余（tooltip/颜色/网格）不动，报告箱线图无统计表，不引入前端增强项（保持最小修复）。

### 2. 补 pytest 用例（TDD）

文件：main/core/tests/unit/test_html_report.py（已有 400+ 行用例，直接追加）：

- `test_boxplot_data_requires_min_5_samples`：`_boxplot_data([1,2,3,4])` → None；`_boxplot_data([1,2,3,4,5])` → 五数列表。
- `test_box_chart_drops_sparse_year_without_axis_misalignment`：构造 `returns_buckets.yearly` 含一个 <5 样本年份（夹在两个正常年份中间），调 `_box_chart`，断言该年份不在 categories，且 categories 与 box_data 等长对齐。
